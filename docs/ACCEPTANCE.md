## 二、用户使用流程

### 场景 1：日常复制-召回-粘贴（主循环）

```
复制任何内容（⌘C / 右键复制 / 截图 / 他人分享）
        │  ← 0.35s 内被捕获，刘海右侧条数 +1
        ▼
需要早前的内容时 ──→ ⌘⇧V（或鼠标悬停刘海）
        │
        ▼
┌ 面板 ────────────────────────────┐
│ 输入即搜（支持中英文，来源 App 名也可搜）│
│ 类型 chips：全部/文本/链接/文件/图片     │
│ ↑↓ 移动高亮（列表自动滚动跟随）          │
│ 1-9 直接粘贴对应条目（不用按回车）        │
│ ⏎ 粘贴高亮条目                          │
│ 鼠标悬停条目 → 出现 置顶📌/编辑✨/OCR🔍/删除🗑│
│ Esc：清搜索 → 清筛选 → 收面板（三级渐进）  │
└─────────────────────────────────┘
        │ 选中后
        ▼
面板收起 → 内容写入剪贴板 → 自动激活之前的应用 → 合成 ⌘V
（未授权辅助功能：只复制，回到目标应用自己 ⌘V）
```

### 场景 2：截图 → 标注 → 使用

```
⌘⇧6（或菜单栏 → 截图）
    │ 全屏冻结 + 暗化
    ▼
拖框选区（实时尺寸标签；移动时显示光标处颜色 HEX，⌘C 复制色值）
    ├─ Esc 取消 / 单击取消
    ├─ ⏎ 捕获整个屏幕
    └─ 松手 = 选定
         ▼
缩略图"悬挂"在刘海下 2.5s → 自动进入剪贴板历史（可直接 ⌘V 到别处）
    ├─ 同时存文件（~/Pictures/ClipIsland，可在设置关闭/改路径）
    └─ 默认打开编辑器
         ▼
编辑器：矩形/椭圆/箭头/画笔/文字/高亮/马赛克/裁剪/选择移动
    8 色标注 · 笔画粗细/字号可选 · ⌘Z 撤销 ⇧⌘Z 重做 · ⌫ 删所选
    文字工具：点击放置 → 直接输入 → ⏎ 确认（空文字自动丢弃）
    裁剪：拖出区域 → ⏎ 或「应用裁剪」（标注坐标同步平移）
         ▼
复制（入历史+剪贴板）/ 保存（PNG 落盘+缩略图提示）/ 完成（关闭）
```

### 场景 3：图片 OCR

两条入口：编辑器工具栏「🔍文字识别」按钮；或历史列表图片条目悬停时的取景器按钮。
识别在本机 Vision 框架完成（中英文），结果面板 →「复制到剪贴板」→ 自动进入历史。

### 场景 4：管理历史

- **置顶**：条目悬停 → 📌（置顶组永远在最上，且不参与容量淘汰）
- **删除**：悬停 → 🗑（图片条目会同时删掉磁盘 PNG）
- **清空**：菜单栏图标 → 清空历史（含置顶全部清掉）
- **暂停**：菜单栏 → 暂停监控（刘海条显示 ⏸ 图标；临时给密码管理器场景用）
- **敏感内容**：1Password/Bitwarden 等带 nspasteboard 标记的复制永不入库

### 场景 5：设置（菜单栏 → 设置…，⌘,）

通用：开机自启 / 容量(100-2000) / 点击行为(自动粘贴|仅复制) / 悬停展开开关 /
截图存文件与目录 / 截图后是否开编辑器。
快捷键：面板与截图各 4 组预设。
权限页：两项 TCC 权限状态灯 + 去授权按钮 + 刷新。

## 三、逻辑梳理

### 3.1 模块装配（AppCoordinator 单点接线）

```
main.swift (.accessory)
 └ AppDelegate
    └ AppCoordinator.start()
       ├ ClipStore(~/.app support/ClipIsland)      ← SQLite + images/
       ├ ClipboardMonitor ──onCapture──→ store.add
       ├ AutoPaster(monitor)
       ├ HotkeyManager ──panel→ notchModel.toggle / shot→ startScreenshot
       ├ SelectionController ──完成图→ deliverScreenshot
       ├ EditorWindowController[] ──导出→ 剪贴板/文件
       ├ SettingsWindowController / OCRResultWindowController
       └ NotchWindowController(model: NotchModel)  ← 唯一 UI 状态源
```

所有 UI 动作通过 `NotchModel` 的回调（onSelectItem/onTogglePin/onDeleteItem/
onEditItem/onOCRItem/refreshResults…）回 Coordinator 落地，View 层不持有业务。

### 3.2 数据流

**捕获**：Timer 0.35s 轮询 `NSPasteboard.changeCount` → 变化则提取
（敏感标记→丢弃；PNG/TIFF→图片；文件 URL→file；URL→link；其余→text）
→ 附带前台 App 名 → `store.add` → SHA256 去重（命中则刷新时间置顶）→
容量 LRU（最旧未置顶出局）→ SQLite 落盘 + onDidChange → 刘海计数/列表刷新。

**回贴**：面板展开前 `noteFrontmost()` 记录目标 App → 选中条目 → 收面板 →
写剪贴板（`markOwnWrite` 防自记录）→ 延时 100ms 激活原 App → 再 140ms 后
CGEvent 合成 ⌘V。全程无权限时静默降级为仅复制。

**截图**：预检权限 → 收面板 → 隐藏刘海窗 → 一次性冻结全部屏幕
（CGWindowListCreateImage，含 RGBA8 位图供取色）→ 每屏一个全屏覆盖窗
（画冻结图+暗化，跨屏选区用 ghost 矩形镜像）→ 松手 → 全局坐标裁剪
（含 Retina 缩放与上下翻转）→ 入历史 + 存文件 + 悬挂缩略图 + 开编辑器。

**编辑器**：标注存图像像素坐标（左上原点），与视图解耦；预览 = CGContext
按比例合成（版本号缓存），导出 = 同一渲染器 1:1 合成，所见即所得；
马赛克 = 选区无插值降采样再升采样（缓存 tile）；裁剪改基图并平移全部标注。

### 3.3 关键状态机

```
NotchModel.phase:  collapsed ⇄ expanded
  展开：悬停250ms / 点击 / ⌘⇧V（展开前记录前台App、注入权限提示）
  收起：移开300ms / 点击 / Esc / 选中条目 / 截图开始

Esc 三级：query 非空 → 清空搜索；有类型筛选 → 清筛选；否则收面板
面板键盘：输入框持有焦点时吃字符（支持中文 IME），
         空输入框时 1-9 直选；↑↓/⏎/Esc 任何时候都由模型处理
```

### 3.4 权限与降级矩阵

| 权限 | 影响 | 降级行为 |
|---|---|---|
| 辅助功能 | 合成 ⌘V | 面板顶部橙色横幅引导，点击跳系统设置；仅复制 |
| 屏幕录制 | CGWindowList 捕获 | 预检失败跳系统设置；API 失败自动切 `screencapture` CLI 兜底 |

### 3.5 已知边界（设计内）

- 数字直选/回车都直接触发粘贴（直选=粘贴，无"仅选中"中间态，Esc/↑↓ 均可见高亮）
- 第一次验收中一次 pbpaste 空读数为剪贴板并发写读的瞬态，重测 4 采样稳定
- 裸二进制与 .app 是两个 TCC 身份，切换启动方式后需重新授权
- debug 二进制必须 adhoc 签名后运行（dev-run.sh 已内置），否则注册热键被 SIGKILL
